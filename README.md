# Dynamic Nim

Mathematical strategy puzzle prototype based on deterministic transformations of Nim-like board states.

The full implementation brief is in [TASK.md](./TASK.md).

This repository is being implemented as an L1–L10 playable web prototype with:
- deterministic rule engine
- solver-based AI
- static Nim levels (L1–L5)
- Gravity Down levels (L6–L10)
- level validator
- automated tests
- mouse/touch swipe input
- CRT terminal presentation
